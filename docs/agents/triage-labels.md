# Rótulos de triagem

As skills usam cinco rótulos canônicos. Neste rastreador local, eles são registrados na linha `Status:` de cada ticket.

| Rótulo canônico | Rótulo local | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Precisa de avaliação |
| `needs-info` | `needs-info` | Aguarda informação do solicitante |
| `ready-for-agent` | `ready-for-agent` | Especificado o suficiente para um agente trabalhar sem acompanhamento |
| `ready-for-human` | `ready-for-human` | Requer implementação humana |
| `wontfix` | `wontfix` | Não será implementado |

Quando uma skill pedir um rótulo, use o valor correspondente da coluna “Rótulo local”.
