# Documentação de domínio

Orientações para as skills que exploram a linguagem e as decisões deste repositório.

## Antes de explorar

- Leia `GLOSSARY.md`, quando existir.
- Se existir `GLOSSARY-MAP.md`, consulte o glossário dos contextos relevantes.
- Leia em `docs/adr/` as decisões que se aplicam à área do trabalho.

Se esses arquivos ainda não existirem, prossiga sem apontar a ausência. O glossário e os ADRs são criados conforme termos ou decisões forem resolvidos, não como etapa inicial obrigatória.

## Organização

Este é um repositório de contexto único: o glossário fica na raiz e os ADRs ficam em `docs/adr/`.

## Uso dos termos

Use a terminologia definida no glossário em títulos de tarefas, propostas e testes. Se o termo necessário não estiver registrado, sinalize a lacuna para resolução com `domain-modeling`.

## Conflitos com ADRs

Se uma proposta contrariar um ADR existente, mencione o conflito explicitamente em vez de substituí-lo sem discussão.
